# **Smart Community**

## **Idea general**

### **Producto mínimo viable**

Es un SAAS multi-tenant para administrar recaudaciones de cuotas mensuales o anuales de seguridad, mantenimientos, reparaciones etc, en las comunidades. Se busca tener una aplicación para la que la comunidad tanto en la junta directiva como los vecinos, puedan llevar un control de las recaudaciones.

- Se puede pagar más de una cuota a la vez, de cualquiera de las recaudaciones que se creen.

- Al hacer un pago se genera un PDF para el vecino, se puede descargar para enviar por whatsapp o correo, y el vecino puede visualizar su pago y descargarlo en el sitio de la aplicación comunitaria.

- Solo se entrega un acceso por casa.

- Historial de montos de cobros mensuales, teniendo siempre un histórico de los cambios que se dan para mayor transparencia.

- Características adicionales:
  - Puede generar un listado de visitas diarias para la seguridad

  - Puede generar un listado de accesos permanentes para los negocios

  - Mantiene un censo de vecinos:
    - Mayores de 18 años | Menores de 18 años

    - Propia | Alquiler | Prestada | Familiar | Otro

    - Negocio | Casa | Apartamentos | Religioso | Escuela | Terreno | Otro

    - Tipo de estructura ( número de pisos, cuenta con cisterna u otro tipo de contendor para agua )

### **Mejoras a mediano plazo**

Una vez en producción la aplicación, una de las mejoras va a ser la ubicación geo referenciada de las propiedades dentro del polígono de la comunidad, esto ayudara a no crear vecinos fuera del area que cubre la comunidad y generar un mapa actualizado de las propiedades para que la seguridad sepa a dónde se dirigen las visitas que llegan y en el futuro un sistema de alerta para diferentes tipo de situaciones en las que la seguridad debe actuar de acuerdo al contrato y acuerdos con el personal o empresa de seguridad.

- Mensajes y notificaciones controlados y específicamente para consultas entre la junta directiva y los vecinos.

- Polígono de cobertura de comunidad

- Propiedades geo referenciadas

- Ubicación para las visitas

- Ubicación para alertas de vecinos para la seguridad

- Dashboard de notificaciones comunitarias para publicaciones varias:
  - Alquileres | Ventas

  - Servicios de mantenimientos

  - Mascotas extraviadas

  - Ventas de garage

### **Mejoras a largo plazo**

- Generar QR con control de hora de entrada y fecha para visitas.

- Pluma automatizada para vecinos ( solo en caso de falta de energía requiere de personal ).

- Sistema de votaciones electrónicas de junta directiva (opcional) \-\> proyecto aparte.

- Sistema de votaciones (opcional ) para prioridades de proyectos comunitarios, proveedores de servicios, etc.

- Vigilancia con drones (opcional) \-\> como proyecto separado.

- Board como manejador de bienes raíces con diferentes comunidades.
